# GiftStory

A personal gift notebook. Remember what each person likes, the dates that matter, and what you already gave.

Package: `com.GiftStoryMNG.GiftStory`

Remote config: [N293.json](https://api2.blwsmartware.net/N293.json) — `disable=1` hides Google Play Billing popups only. Shop stays open for coin unlocks.

| Product ID | Type |
| --- | --- |
| `gs_pack_1` … `gs_pack_10` | Consumable coins |
| `gs_remove_ads` | Non-consumable |
| `gs_pro` | Non-consumable, more than 4 people |

People, ideas, memories, and reminder photos stay on the device. Occasion reminders are local notifications. No account, no gift store, and no automatic gift suggestions.
